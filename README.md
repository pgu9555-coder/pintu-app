# 拼途 Pintu

一个帮朋友聚会的轻量 Web App：**约在哪 → 吃什么 → 谁买单 → 怎么分钱**，一条龙搞定。

单文件纯前端（一个 `index.html`），无需构建、无需 npm，双击就能跑；配好后端后支持多人实时协作。

---

## 功能

| 功能 | 说明 | 是否需要联网后端 |
|---|---|---|
| **公平碰面 · 盲盒吃喝** | 输入几个人的出发地，算出公平碰面点，推荐周边商圈与餐饮，可滑卡盲盒选店 | 否（协作模式需要） |
| **谁买单 · 转盘** | 把在场的人填进转盘，转一转决定谁买单。决定内容可自定义（谁点菜／谁开车…） | 否 |
| **行程账本** | 多天行程记账，各付各的，最后一键算清谁该转给谁 | 否（共享账本需要） |
| **协同组局房间** | 建房间拿 6 位房间码，朋友凭码加入；碰面点、账本在成员间**实时同步** | 是 |

数据存储：
- 未配置后端时，行程账本等数据存在浏览器 `localStorage`，仅本机可见。
- 配置后端后，房间／共享账本／碰面点存在腾讯云开发（CloudBase），跨设备实时同步。

---

## 技术栈

- 纯 HTML / CSS / 原生 JavaScript，**无框架、无构建步骤**
- [高德地图 JS API 2.0](https://lbs.amap.com/) — 定位、地址联想、POI 搜索、地图绘制
- [腾讯云开发 CloudBase](https://tcb.cloud.tencent.com/) — 匿名登录 + 文档型数据库 + 实时监听（`.watch()`）
- 结算图片分享使用原生 Canvas，无第三方依赖

## 快速开始

### 本地预览

```bash
git clone <你的仓库地址>
cd pintu
# 直接用浏览器打开 index.html 即可
```

> 注意：用 `file://` 直接打开时，浏览器定位 API 会被限制。建议起一个本地静态服务：
>
> ```bash
> python3 -m http.server 8000
> # 然后访问 http://localhost:8000
> ```

### 配置（要用联网协作功能才需要）

打开 `index.html`，在文件**最顶部**找到 ★ 标记的三处，替换成你自己的值：

| 标记 | 位置 | 说明 |
|---|---|---|
| ★① | `window._AMapSecurityConfig.securityJsCode` | 高德安全密钥 |
| ★② | `<script src="https://webapi.amap.com/maps?...key=XXX...">` | 高德 Key（服务平台需选 **Web 端 (JS API)**） |
| ★③ | `var CLOUDBASE_ENV_ID = "..."` | 腾讯云开发环境 ID |

**后端准备（CloudBase）：**

1. 在 [CloudBase 控制台](https://tcb.cloud.tencent.com/) 新建环境，复制**环境 ID**
2. 身份认证 → 登录方式 → 开启**匿名登录**
3. 文档型数据库 → 新建集合，名称必须为 **`rooms`**
4. 给 `rooms` 设置权限。协作功能要求所有成员都能读写同一条记录，因此需要**自定义安全规则**：
   ```json
   { "read": true, "write": true }
   ```
   > 免费/体验版环境不支持自定义安全规则，需升级为付费套餐才能配置。
5. 环境管理 → 安全配置 → **WEB 安全域名**，加入你的部署域名

**高德准备：**

在高德控制台给 Key 绑定**域名白名单**（填部署域名，不带 `https://`）。这是防止 Key 被盗用的主要手段。

### 部署

任意静态托管即可，只要最终是 **HTTPS**（定位 API 在非 HTTPS 页面会失败）：

- **CloudBase 静态网站托管**（推荐，与后端同平台，自动带 HTTPS，国内访问快）
  上传 `index.html` 到**根目录**，文件名保持 `index.html`
- 或 Vercel / Netlify / GitHub Pages 等
  > 面向国内用户时注意：`*.vercel.app` 等境外域名在国内可能无法访问或很慢。

## 关于仓库中的密钥

`index.html` 中包含高德 Key、securityJsCode 和 CloudBase 环境 ID。

这些是**前端密钥**——任何用户打开网页后按 F12 都能看到，无法隐藏，这是纯前端应用的固有特性。它们的安全性**不依赖保密，而依赖白名单**：

- 高德 Key → 由**域名白名单**限制，未在白名单内的站点无法调用
- CloudBase 环境 ID → 由 **WEB 安全域名**限制

因此仓库公开是可接受的。但请务必：

1. **配好上述两处白名单**，否则 Key 会被任意站点盗用配额
2. **绝不要**把腾讯云 `SecretId` / `SecretKey`、高德 Web 服务端密钥等**服务端密钥**写进本文件或提交到仓库

如果你 fork 本项目，请替换成你自己的 Key 与环境 ID。

## 已知限制

- **并发写入**采用「最后写入者覆盖」策略。多人几乎同时操作时，理论上可能有一次修改被覆盖；小规模使用不受影响。
- **共享账本的成员**与房间成员是两套列表，房间新增成员不会自动出现在已建好的账本中。
- **商场详情**中的分类数量按半径范围统计，会包含商场临街店铺，不等同于「楼内店铺数」。
- 目前界面仅有中文。
