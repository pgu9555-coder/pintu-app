# 拼途微信小程序 Web-View 外壳

此目录是可独立导入微信开发者工具的最小小程序项目。它只承载拼途 H5 页面：

`https://pintu-d4g77ecn24b674fa0-1303073868.tcloudbaseapp.com/index.html`

## 使用方式

1. 在微信开发者工具中导入本目录 `miniprogram-shell`。
2. 确认 AppID 为 `wxe1fe19432c29e3cd`。
3. 使用真机预览或体验版扫码验证 H5 页面加载。

## 发布前置条件

- 在小程序管理后台的“开发管理 / 开发设置 / 业务域名”中配置并校验 H5 所在业务域名：`pintu-d4g77ecn24b674fa0-1303073868.tcloudbaseapp.com`。`web-view` 只能打开已配置的业务域名。
- 业务域名配置需要非个人主体的小程序账户；个人主体不能配置业务域名，也无法以此 Web-View 方案完成发布。
- 扫码登录、支付或其他微信网页能力需由 H5 按其各自规则完成配置与验证；本外壳不申请或伪造任何权限。
- 开发者工具内的模拟器不等同真实环境。提交审核前，必须在真机预览或体验版中完成扫码登录、页面跳转和异常加载验证。
- 提交审核前，请确认已完成业务域名校验、H5 可公网访问、账号主体与类目满足要求，并按实际功能准备审核所需说明、测试账号或测试路径。

## 结构

- `project.config.json`：开发者工具项目与 AppID 配置。
- 项目根目录下的 `app.*` 与 `pages/`：小程序源码；首页以全屏 `web-view` 打开拼途 H5。
