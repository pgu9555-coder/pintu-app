# 拼途原生微信小程序

这是拼途的原生微信小程序版本，不使用 `web-view`、DOM 或第三方运行时。

## 导入方式

1. 用微信开发者工具导入本目录 `miniprogram-shell/`。
2. AppID：`wxe1fe19432c29e3cd`。
3. CloudBase 环境：`pintu-d4g77ecn24b674fa0`。
4. 确认项目关联到该 CloudBase 环境，且 `roomGateway` 云函数已部署。

## 功能

- 首页统一输入 8 位房间码，自动识别碰面或账本房间并跳转。
- 碰面房间：成员选择／更新出发地、显示参考中点、添加候选地点、投票、由房主确认或重新选择。
- 共享账本：管理手动成员，新增／修改／删除支出，选择付款人与分摊人，生成结算建议。
- 房间创建者可解散，其他成员可退出；房间在房主解散前永久存在。
- 转盘完成约 2 秒的可见动画后再显示结果。
- 房间页面每 2 秒通过 `roomGateway` 拉取最新状态。

参考中点只是坐标估算；最终去处应结合真实交通在候选地点中共同确认。

## 隐私与权限

小程序使用 `wx.chooseLocation` 选择本人出发地或候选地点。发布前必须在微信公众平台隐私保护指引中如实声明位置信息，并完成相关接口授权。复制房间码会写入剪贴板，也应在隐私指引中说明。

## 平台隔离

小程序房间只能由小程序用户加入，Web 房间只能由 Web 用户加入。平台由云函数根据可信调用上下文识别，客户端不能伪造。旧的、缺少平台标记的房间不会迁移。
